# 社区功能

## 模块范围

社区模块负责账号、用户资料、帖子、评论、点赞、收藏、关注、通知、分类、标签和媒体上传。MySQL 保存最终业务状态，Redis 和 RabbitMQ 用于提升访问性能和解耦部分异步处理。

## 认证与用户

用户通过 `/auth/register` 注册，通过 `/auth/login` 获取 JWT。访问受保护接口时携带：

```http
Authorization: Bearer <token>
```

认证模块还提供验证码、用户 ID 可用性检查、当前用户、Token 刷新和退出登录。用户模块负责：

- 用户搜索、公开资料和个性标签。
- 用户帖子、收藏、点赞和统计。
- 资料、密码和账号维护。
- 关注、粉丝、互关和关注状态。
- 用户认证申请、状态查询和撤销。

公开读取和登录后写入的边界见 [API.md](API.md)。

## 帖子

帖子支持图文和视频内容，关联分类、标签、图片与视频。核心流程包括：

- 创建、编辑和删除帖子。
- 列表、详情、作者主页和分类/标签筛选。
- 帖子评论、点赞和收藏。
- 全文搜索与旅行助手知识库同步。

MySQL 中的帖子记录是事实来源。创建、编辑、草稿状态变化或删除帖子时，业务层需要同步处理：

- 互动统计和关联数据。
- 全文索引的新增、刷新或删除。
- RAG 分块索引的新增、刷新或删除。

索引状态及失败补偿见 [SEARCH_RAG.md](SEARCH_RAG.md)。

## 评论与互动

`comments` 支持评论和回复，公开接口可读取指定评论的回复；发表评论和删除评论需要登录。

点赞和收藏均使用独立关系表保证用户与目标之间的唯一关系。RabbitMQ 当前参与点赞消息处理；Redis 可缓存用户互动集合和计数。数据库关系仍是最终判断依据，缓存不可作为永久数据源。

关注模块维护用户之间的单向关系，并派生粉丝、关注和互关查询。

## 通知

通知类型覆盖评论、点赞、关注和收藏。登录用户可以：

- 查询未读总数和分类未读数。
- 按互动类型读取通知列表。
- 标记单条或全部通知为已读。
- 删除通知。

通知接口均依赖当前登录用户。若 `/notifications/unread-count` 返回 `403`，应先检查请求是否携带有效 Bearer Token，而不是将其视为公开统计接口。

## 分类和标签

分类用于帖子的主要业务归类，标签提供多对多主题关联和热门标签展示。普通用户读取分类和标签；后台负责维护数据。

## 媒体上传

`/upload` 提供单图、多图和视频上传，后端校验文件大小与 MIME 类型后写入 COS：

- 图片默认上限 20 MB。
- 视频默认上限 500 MB。
- COS 密钥、桶名和访问域名通过环境变量提供。

真实存储凭据不得写入代码、文档或提交的环境文件。
